    Collaboration Settings Reference
    • Enable Collaboration: turns collaboration runtime behavior on or off.
    • Show Collaboration Toolbar: displays or hides the dashboard collaboration toolbar when collaboration is enabled.
    • Collaboration mode: Independent is local-first, Asynchronous is team coordination without strict real-time sync, Synchronous expects checkpointed sync, and Real-time targets continuous updates.
    • Toolbar position: places the collaboration toolbar in the selected corner.
    • Provider ID, Name, and Status: identify the active provider and its health state.
    • Discovery scope: controls whether discovery is evaluated at resource, workspace, or organization visibility levels.
    • Allow discovery directory listing: permits broader listing in discovery snapshots.
    • Require approval before sharing access: marks sharing as approval-gated.
    • Allow guest share links: enables guest-link style sharing policy.
    • Default share expiry (days): default duration for new shared access patterns.
    • Sharing channels: comma-separated channel defaults used by sharing and discovery summaries.
    • Enable synchronization and Sync mode: control whether sync runs and whether it is manual, scheduled, or real-time.
    • Conflict strategy: Manual Review performs no automatic merge, Latest Write Wins applies incoming metadata/comments, Metadata Priority applies incoming metadata fields, and Append Comments appends incoming comments.
    • Auto-merge comments and Auto-merge metadata: toggle automatic merge behavior when strategy allows it.
    • Keep version history and Maximum versions per resource: control synchronized version retention behavior.
    • Record Sync Checkpoint: stores the latest sync timestamp in collaboration state.
    • Reset to Baseline: reapplies Solo or Team baseline defaults and clears transient operational collaboration data.
    • Live collaboration server URL and Quick Start actions: connect to a collaboration server and start a live multi-user session in as few steps as possible.
    • Publish Async Snapshot and Pull Async Snapshot: exchange collaboration metadata asynchronously through shared network storage managed by the server.
    • Generate Discovery Snapshot: creates a point-in-time list of discoverable resources under current policy.
    • Queue Test Conflict: adds a synthetic pending conflict with incoming metadata/comments.
    • Resolve Oldest Conflict: resolves the oldest pending conflict using the selected strategy and records resolution details.
    • Register Presence Session and Clear Collaboration Sessions: manage active collaboration presence records.
    • Permission profile controls: create or update named permission profiles.
    • Permission assignment controls: add principal/resource permission assignments.
    Recommended Defaults
    • Solo workflow: use Apply Solo Defaults for independent mode, manual sync behavior, resource-level discovery, and conservative sharing defaults.
    • Team workflow: use Apply Team Defaults for asynchronous mode, scheduled sync, workspace-level discovery, and team-oriented permission profiles.

    The preset summary line shows Solo or Team when current settings match those defaults. If settings diverge, it shows Custom.

    Collaboration Glossary
    • Discovery snapshot: point-in-time list of resources discoverable under current sharing policy.
    • Presence session: active collaboration presence record tied to user/resource context.
    • Conflict queue: list of pending synchronization conflicts waiting for resolution.
    • Sync checkpoint: saved timestamp for the most recent recorded synchronization event.
    • Conflict resolution detail: recorded strategy outcome showing if automatic metadata mutation was applied.
