        Storage Providers

        ART always works with local files. Additional storage providers are optional and are never required for local functionality.

          Google Drive Connection

          Connecting requires a Google Drive OAuth Client ID configured by an ART administrator. ART requests access only to files it creates or you open, never your entire Google Drive. Connecting opens a Google sign-in popup; allow popups for this site if the browser blocks it.

          Microsoft OneDrive Connection

          Connecting requires a Microsoft Azure AD Application (Client) ID configured by an ART administrator. ART requests access only to its own App Folder (the Files.ReadWrite.AppFolder scope), never your entire OneDrive. Connecting opens a Microsoft sign-in popup; allow popups for this site if the browser blocks it.

          Dropbox Connection

          Connecting requires a Dropbox App Key (registered with "App folder" access) configured by an ART administrator. ART only ever accesses its own dedicated App Folder, never your entire Dropbox. Connecting opens a Dropbox sign-in popup; allow popups for this site if the browser blocks it.

          Organization Statistics

          Organization Statistics are optional.

          Organization Statistics aggregate accessibility data across reports that share the same Organization/Client value. Enabling this adds an Organization menu and an optional Dashboard section. Stand-alone reports without an Organization/Client value continue to work normally and are never assigned to an organization.

          Optional statistics sections

          Turn off any section you do not want. Hidden sections are removed from the Organization Statistics dialog.

          Organization Folders

          Organization Folders enable file-based collaboration.

          Configure a shared folder to enable collaboration on ART files, shared tasks, progress logs, and organization metrics. The folder can be on Google Drive, OneDrive, Dropbox, a network drive, or any synchronized folder accessible to your system.
