# ART Packages

This directory stores non-executable ART packages that are registered by the Plugin Framework after existing ART workflows complete.

Package categories:

- accessibility-standards
- report-templates
- dashboard-layouts
- keyboard-profiles
- working-view-presets
- saved-searches
- sample-data
- documentation-packages
- integration-providers
- future-package-types

Packages are treated as resources and metadata containers. They do not execute application code.
