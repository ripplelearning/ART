# ART User Guide

## Workspace Views
ART supports two workspace views:

- Dashboard (default)
- Explorer (optional)

Switch views using View menu, Global Context Menu, Command Palette, Menu Bar Command Search, or optional custom shortcuts.

## Explorer Basics
Explorer presents resources in a hierarchy and adapts automatically to context.
Use keyboard or pointer input to select resources.
Use Enter or Space to activate the selected resource command.

## Explorer Search
Use the Explorer search box to find resources in the current context.
Search results are powered by Universal Search and share history/saved searches.

## Accessibility
Explorer supports keyboard-first navigation, screen readers, and context menu invocation via Applications key or Shift+F10.
